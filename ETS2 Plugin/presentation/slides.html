The problem

Critical info is buried in the game screen

While driving, your speed, fuel, and engine health live inside the game's on-screen dashboard — so you take your eyes off the road to check it.

What if that info lived on a physical device beside you — updating live?
What it is

A physical dashboard for the game

%%SPEED%%%%FUEL%%%%ENGINE%%%%TRUCK%%%%PARK%%%%REST%%%%HAZARD%%%%LEFT%%
MX CREATIVE CONSOLE — live warning indicators
A plugin that reads live game data and shows it as color-coded warning lights on physical keys.
  • Green = good, Red = take action
  • 8 live indicatorsSpeed · Fuel · Engine · Truck damage · Brake · Rest · Hazards · Turn signals
